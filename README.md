# 📚 통합 도서 검색

BookOasis 미디어 서버에서 코어 수정 없이 메타데이터 검색과 라이브러리 관리를 안정적으로 지원하는 통합 도서 검색 플러그인 패키지입니다. 국립중앙도서관, 알라딘, 네이버, 구글의 도서 데이터를 스레드 풀(Thread Pool) 기반으로 병렬 조회하고, 우선순위 규칙에 따라 하나의 서지정보로 자동 합성합니다.

**현재 버전: v1.5.5**

---

## 🔄 처리 흐름 (Pipeline)

```
[검색 요청]
   │
   ├─ 1. [로컬 판정] DB에 이미 저장된 isbn 컬럼값 확인
   │       └─ 유효한 ISBN이면 → 3단계로 이동
   │
   ├─ 2. [링크 파싱] 검색어 내 URL 또는 DB link 컬럼(HTML)에서 ISBN 역추적
   │       └─ 추출 성공 시 → 3단계로 이동
   │
   ├─ 3. [API 호출]
   │       - ISBN이 있으면: ISBN 기준으로 국립중앙도서관/알라딘/네이버/구글 동시 조회
   │       - ISBN이 없으면: 제목 + 저자(DB에 있는 경우) 기준으로 동시 조회
   │       - API 키가 없는 소스는 요청 없이 자동 바이패스
   │
   ├─ 4. [메타데이터 합성 및 정렬] ★ 핵심 단계
   │       - 여러 소스 결과를 우선순위 규칙으로 병합해 맨 위에 하나의 "통합" 결과로 제시
   │       - 정렬 우선순위: ISBN 일치 결과 > 책 제목 일치 결과
   │
   └─ 5. [사용자 최종 확정 및 저장]
           - 통합 결과 또는 개별 소스 결과 중 원하는 것을 선택해 저장(apply)
```

---

## 🧩 4단계: 메타데이터 합성 규칙

2개 이상의 소스에서 결과를 얻으면, 개별 결과들과는 별도로 **하나의 "[통합/합성]" 결과**를 목록 맨 위에 추가로 제시합니다.

| 항목 | 우선순위 |
| :--- | :--- |
| **표지(Cover)** | 설정화면에서 선택한 소스(기본값: 알라딘)에 표지가 있으면 무조건 그 표지를 사용. 없으면 국립중앙도서관 → 알라딘 → 네이버 → 구글 순으로 대체 |
| **서지정보** (제목/저자/출판사/출간일/ISBN) | 국립중앙도서관 → 알라딘 → 네이버 → 구글 순으로, 값이 있는 첫 소스를 채택 |
| **그 외 정보** (설명, 링크 등) | 위와 동일한 우선순위로 필드별 개별 병합 |

소스가 1개뿐이면 병합할 실익이 없으므로 통합 결과를 생성하지 않고, 해당 소스의 결과만 그대로 보여줍니다.

> ℹ️ 표지 우선 소스는 설정화면(`COVER_PRIORITY`)에서 변경할 수 있지만, 서지정보 우선순위(국립중앙도서관 > 알라딘 > 네이버 > 구글)는 고정값입니다.

| :--- | :--- |
| **⚡ 초고속 병렬 검색** | 국립중앙도서관, 알라딘, 네이버, 구글 도서 API를 동시에 백그라운드로 호출하는 `ThreadPoolExecutor` 기술을 가동하여 전체 검색 속도를 비약적으로 단축시킵니다. |
| **🧬 메타데이터 자동 합성** | 여러 소스의 결과를 우선순위 규칙에 따라 하나의 완성된 서지정보로 합성하여 제시합니다. (위 4단계 참고) |
| **🖼️ 고해상도 커버 수집** | 원본에 가까운 표지 품질 확보를 위해 소스별 이미지 주소를 정제하여 가장 선명한 최고 화질의 커버를 다운로드합니다. |
| **🔗 링크(LINK) 기반 ISBN 역추적** | 검색어에 서점/쇼핑몰 상세페이지 URL이 섞여 있거나, DB에 저장된 `link` 컬럼이 있는 경우 해당 페이지의 OG 메타태그(`books:isbn`) 또는 본문 텍스트를 파싱해 ISBN을 역으로 추적합니다. |
| **🎯 정밀 매칭 원천 추적** | ISBN 정밀 검색 성공 시 어떤 경로로 도서를 식별했는지 타이틀 접두사에 명확히 구분해주며, 끝자리에는 별표(`*`)를 기입하여 식별성을 강화합니다.<br>- `[알라딘/ISBN]` : 직접 ISBN을 입력해 검색함<br>- `[네이버/LOCAL]` : DB에 이미 저장돼 있던 ISBN 컬럼 값을 사용함<br>- `[구글/LINK]` : 검색어 또는 DB의 URL을 파싱해 ISBN을 역추적함<br>- `[통합/합성]` : 여러 소스를 병합한 자동 합성 결과 |
| **🧾 상세 진행 로그** | `search()` 호출 시점부터 종료까지, 검색어가 ISBN으로 판정됐는지 제목으로 판정됐는지, 어떤 경로(LOCAL/LINK/INPUT)로 감지됐는지, 각 API의 요청·응답·채택 건수, 합성에 참여한 소스까지 단계별로 콘솔에 로그를 남겨 디버깅이 쉽습니다. |
| **🔌 API 키 미설정 자동 바이패스** | 국립중앙도서관/알라딘/네이버/구글 중 API 키가 설정되지 않은 소스는 요청 자체를 보내지 않고 자동으로 건너뜁니다(로그에 `바이패스`로 표시). 불필요한 요청 실패나 쿼터 소모를 방지합니다. |
| **🔐 기존 ISBN 데이터 보호** | 신규 검색 결과에 ISBN 정보가 비어 있는 경우에도, 기존 데이터베이스에 저장되어 있던 소중한 ISBN 데이터가 공백으로 덮어씌워져 지워지지 않도록 `COALESCE / NULLIF` 안전 쿼리를 수행합니다. |
| **📂 임포트 섀도잉 방지** | 다른 플러그인이나 코어에 `utils.py`가 존재하여 이름이 충돌하는 문제를 방지하기 위해 파일명을 `utils_unified.py`로 변경하고, **절대 경로 기준 동적 모듈 로드(`importlib`)** 방식을 도입하여 작동의 안전성을 보장합니다. |
| **⚙️ DB Row 크래시 원천 차단** | 데이터베이스 게이트웨이가 반환하는 Row 객체에서 `.get()`을 직접 호출할 때 발생할 수 있는 `AttributeError` 예외를 감지하여, 안전하게 데이터 검색 및 저장 구문을 실행하는 내부 헬퍼(`get_row_val`)를 내장했습니다. |

## 🔎 ISBN 감지 우선순위 (1~2단계 상세)

1. **INPUT** — 검색어 자체가 유효한 ISBN-10/13 형식인 경우
2. **LOCAL** — 로컬 데이터베이스에 이미 등록된 도서의 `isbn` 컬럼 값이 유효한 경우 (네트워크/파일 접근이 없는 최우선 무료 판정)
3. **LINK (검색어 내 URL)** — 검색어 문자열에 서점/쇼핑몰 URL이 포함된 경우, 해당 페이지를 파싱해 ISBN 추출
4. **LINK (DB link 컬럼)** — 위 방법이 모두 실패했을 때, 같은 레코드의 `link` 컬럼(서점/쇼핑몰 URL)을 파싱해 ISBN 추출

전부 실패하면 정제된 원래 검색어(+DB에 저장된 저자가 있다면 함께)로 제목 검색이 수행됩니다.

> ℹ️ **참고**: 이전 버전에 있던 EPUB/PDF 파일 내부 판권지 정규식 스캔 기능과 Gemini/LiteLLM 기반 AI 판독 기능은 v1.5.5부터 이 플러그인에서 완전히 제거되었습니다.

---

## 💡 링크(LINK) 기반 ISBN 역추적 기술

*   서점/쇼핑몰 상세페이지의 OG 메타태그(`books:isbn`, `og:isbn`)를 1순위로 파싱하고, 메타태그가 없는 페이지(예: 네이버쇼핑 카탈로그)는 본문 텍스트 정규식 스캔으로 2차 백업합니다.
*   데이터베이스 내 도서명과 검색어가 미세하게 불일치하더라도 검색어의 앞 '두 단어'를 파싱하여 부분 일치 매칭(`LIKE %단어%`)하는 백업 쿼리를 구동, 실제 매칭률을 유지합니다.

## 📂 디렉토리 구조 (Directory Structure)

GitHub 배포를 위한 폴더 구조 구성은 다음과 같습니다. 해당 플러그인은 아래 9개의 파일로 긴밀하게 결합되어 구동됩니다.

```text
plugins/metadata/unified_book/
├── __init__.py           # 플러그인 로드 진입점
├── unified_book.py       # 메인 코어 플러그인 (5단계 흐름 제어 및 DB 트랜잭션)
├── aladin.py             # 알라딘 검색 (일반 검색 및 ISBN 전용 API)
├── naver.py              # 네이버 검색 (일반 검색 및 d_isbn 전용 API)
├── google.py             # 구글 검색 (일반 검색 및 Google Volume API)
├── nl.py                 # 국립중앙도서관 검색 (seoji 서지정보 API)
├── utils_unified.py      # 공통 유틸리티 (날짜 정제, 고화질 수집, 링크 파싱, DB 헬퍼)
├── index.html            # 가로형 맞춤 설정 화면 마크업
├── style.css              # 어두운 가로형 맞춤 설정 화면 스타일
└── VERSION               # 자동 업데이트 추적용 버전 파일
```

## 📦 설치 및 적용 가이드 (Installation)

1.  `plugins/metadata/` 경로 하부에 `unified_book` 폴더를 생성하고 패키지 파일들을 배치합니다.
2.  BookOasis 웹 UI의 환경설정 > 플러그인 메뉴에서 `Unified BOOK Search` 활성화 스위치를 켭니다.
3.  국립중앙도서관 인증키, 알라딘 TTBKey, 네이버 Client API 값을 설정하고 저장을 누릅니다. (키가 없는 소스는 자동으로 검색에서 제외됩니다.)
4.  필요하다면 표지 우선 소스를 원하는 소스로 변경합니다. (기본값: 알라딘)
5.  책 상세 정보 수정 > 돋보기 아이콘(검색) 클릭 시, 여러 소스가 자동 합성된 통합 결과와 개별 소스별 결과를 함께 조회하실 수 있습니다.

> ⚠️ **국립중앙도서관 API 필드명 안내**: `nl.py`의 응답 필드 매핑(`TITLE`, `AUTHOR`, `PUBLISHER`, `EA_ISBN`, `TITLE_URL` 등)은 공개 문서를 기준으로 작성되었습니다. 실제 인증키로 테스트했을 때 서지정보가 비어 나온다면, 콘솔에 자동으로 남는 `[국립중앙도서관] 응답 필드명 확인 필요 - 수신된 키: [...]` 로그를 확인해 알려주시면 필드 매핑을 바로잡아 드립니다.

## 📝 변경 이력 (Changelog)

### v1.5.5
- Gemini/LiteLLM 기반 AI 문서 판독 기능 전체 제거
- EPUB/PDF 파일 내부 판권지 정규식 스캔(`ISBN_FILE_SCAN`) 기능 전체 제거
- 검색어/DB `link` 컬럼의 URL을 파싱해 ISBN을 역추적하는 **LINK 감지** 기능 추가
- API 키가 설정되지 않은 소스는 요청 없이 자동 바이패스하도록 변경
- **국립중앙도서관 서지정보(seoji) API 연동 추가** (`nl.py`)
- 처리 흐름을 5단계(로컬 판정 → 링크 파싱 → API 호출 → 메타데이터 합성 → 사용자 확정)로 재설계
- 여러 소스 결과를 우선순위(표지: 설정 가능 / 서지정보: 국립중앙도서관 > 알라딘 > 네이버 > 구글)로 병합하는 **메타데이터 합성** 기능 추가
- 설정화면 레이아웃을 처리 순서(국립중앙도서관 → 알라딘 → 네이버 → 구글 → 합성 옵션)에 맞춰 재배치
- `search()` 전 구간에 단계별 진행 로그(호출/판정/요청/응답/합성/종료) 추가
