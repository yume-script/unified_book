# 📚 통합 도서 검색

BookOasis 미디어 서버에서 코어 수정 없이 메타데이터 검색과 라이브러리 관리를 안정적으로 지원하는 통합 도서 검색 플러그인 패키지입니다. 알라딘, 네이버, 구글의 도서 데이터를 스레드 풀(Thread Pool) 기반으로 병렬 조회하여 높은 신뢰도의 도서 정보를 고속으로 완성합니다.

---

## ✨ 주요 특징 (Key Features)

| 기능 | 설명 |
| :--- | :--- |
| **⚡ 초고속 병렬 검색** | 알라딘, 네이버, 구글 도서 API를 동시에 백그라운드로 호출하는 `ThreadPoolExecutor` 기술을 가동하여 전체 검색 속도를 비약적으로 단축시킵니다. |
| **🖼️ 고해상도 커버 수집** | 원본에 가까운 표지 품질 확보를 위해 소스별 이미지 주소를 정제하여 가장 선명한 최고 화질의 커버를 다운로드합니다. |
| **🏷️ 정돈된 UI 레이아웃** | 소개글 본문(Description) 영역에 서지 정보를 중복 노출하여 지저분해지는 현상을 방지하고, 시스템이 출력하는 `출간일` 영역 끝자리에 `[ISBN: ...]` 값을 결합하여 깔끔한 한 줄 라인으로 출력합니다. |
| **🔗 링크 기반 ISBN 정밀 추적** | DB에 ISBN이 없는 도서라도, 예전에 저장해둔 도서 상세페이지 링크(`link`)를 열어 페이지 안의 `ISBN` 라벨 인근 텍스트를 우선 탐색하고, 실패 시 페이지 전체를 체크섬 검증까지 거쳐 정밀 ISBN을 찾아냅니다. 무거운 파일 스캔이나 외부 AI 호출 없이 가볍게 동작합니다. |
| **🎯 정밀 매칭 원천 추적** | ISBN 정밀 검색 성공 시 어떤 경로로 도서를 식별했는지 타이틀 접두사에 명확히 구분해주며, 끝자리에는 별표(`*`)를 기입하여 식별성을 강화합니다.<br>- `[알라딘/ISBN]` : 검색창에 직접 ISBN을 입력해 검색함<br>- `[네이버/DB]` : 로컬 데이터베이스의 ISBN 기록을 불러옴<br>- `[구글/LINK]` : 저장된 도서 상세페이지 링크를 웹 파싱해서 찾음 (성공 시 서버 로그에도 기록됩니다) |
| **🔐 기존 ISBN 데이터 보호** | 신규 검색 결과에 ISBN 정보가 비어 있는 경우에도, 기존 데이터베이스에 저장되어 있던 소중한 ISBN 데이터가 공백으로 덮어씌워져 지워지지 않도록 `COALESCE / NULLIF` 안전 쿼리를 수행합니다. |
| **📂 임포트 섀도잉 방지** | 다른 플러그인이나 코어에 `utils.py`가 존재하여 이름이 충돌하는 문제를 방지하기 위해 파일명을 `utils_unified.py`로 변경하고, **절대 경로 기준 동적 모듈 로드(`importlib`)** 방식을 도입하여 작동의 안전성을 보장합니다. |
| **⚙️ DB Row 크래시 원천 차단** | 데이터베이스 게이트웨이가 반환하는 Row 객체에서 `.get()`을 직접 호출할 때 발생할 수 있는 `AttributeError` 예외를 감지하여, 안전하게 데이터 검색 및 저장 구문을 실행하는 내부 헬퍼(`get_row_val`)를 내장했습니다. |
| **📝 상세한 오류 로깅** | 알라딘/네이버/구글 API 호출 실패 시 원인을 알 수 없이 조용히 빈 결과만 반환하지 않고, HTTP 에러/연결 실패/응답 파싱 실패를 구분해 서버 로그에 남깁니다. |

## 🔗 링크 기반 ISBN 정밀 역추적 기술

*   **1단계 — 라벨 인접 탐색:** 대부분의 서점 상세페이지는 `ISBN`이라는 라벨을 그대로 노출합니다. 이 라벨 뒤 근접한 값을 우선 추출하여 정확도와 속도를 동시에 확보합니다.
*   **2단계 — 전체 페이지 백업 스캔:** 1단계에서 찾지 못하면 페이지 전체에서 ISBN처럼 생긴 숫자열 후보를 모두 뽑아 ISBN-13/10 체크디지트(Mod 10 / Mod 11)로 검증합니다. 체크섬을 통과하지 못하는 다른 숫자열(상품 ID, 가격 등)은 자동으로 걸러집니다.
*   **노이즈 제거:** `<script>`/`<style>` 블록을 먼저 제거하여 리다이렉트 URL, 해시 파일명 등에서 발생하는 오탐 가능성과 파싱 낭비를 줄입니다.
*   **대형 페이지 대응:** 최대 1.5MB까지 응답을 읽어, 상단에 스크립트/이미지 프리로드 태그가 긴 대형 쇼핑몰 SSR 페이지에서도 본문의 ISBN을 놓치지 않습니다.
*   **유연한 부분 일치 검색:** 데이터베이스 내 도서명과 파일명이 미세하게 불일치하더라도 검색어의 앞 '두 단어'를 파싱하여 부분 일치 매칭(`LIKE %단어%`)하는 3단계 백업 쿼리를 구동, 실제 도서 추적률을 유지합니다.
*   **2단계 자동 백업 검색 (Fallback):** ISBN 검색 결과가 0건이거나 실패한 경우 즉시 전처리 정제된 원래 책 제목 검색으로 Fallback 전환되어 신뢰할 수 있는 도서 검색 결과를 보장합니다.

## 📂 디렉토리 구조 (Directory Structure)

GitHub 배포를 위한 폴더 구조 구성은 다음과 같습니다. 해당 플러그인은 아래 9개의 파일로 긴밀하게 결합되어 구동됩니다.

```text
plugins/metadata/unified_book/
├── __init__.py           # 플러그인 로드 진입점
├── unified_book.py       # 메인 코어 플러그인 (흐름 제어 및 DB 트랜잭션)
├── aladin.py             # 알라딘 검색 (일반 검색 및 ISBN 전용 API)
├── naver.py              # 네이버 검색 (일반 검색 및 d_isbn 전용 API)
├── google.py              # 구글 검색 (일반 검색 및 Google Volume API)
├── utils_unified.py      # 공통 유틸리티 (날짜 정제, 고화질 수집, 링크 ISBN 파싱, DB 헬퍼)
├── index.html            # 맞춤 설정 화면 마크업 (ISBN 감지 / 오픈 API 키 2박스 구성)
├── style.css              # 어두운 테마 맞춤 설정 화면 스타일
└── VERSION                # 자동 업데이트 추적용 버전 파일
```

## 📦 설치 및 적용 가이드 (Installation)

1.  `plugins/metadata/` 경로 하부에 `unified_book` 폴더를 생성하고 패키지 파일들을 배치합니다.
2.  서버를 재시작합니다.
3.  BookOasis 웹 UI의 환경설정 > 플러그인 메뉴에서 `통합 도서 검색` 활성화 스위치를 켭니다.
4.  알라딘 TTBKey, 네이버 Client ID/Secret, (선택) 구글 API Key를 입력하고 저장을 누릅니다.
5.  필요에 따라 "저장된 링크(link)에서 ISBN 웹 파싱 시도" 옵션을 켜거나 끕니다 (기본값: 켜짐).
6.  책 상세 정보 수정 > 돋보기 아이콘(검색) 클릭 시 알라딘/네이버/구글의 정돈된 검색 결과를 즉시 조회하실 수 있습니다.

## ⚠️ 참고: 이전 버전과의 차이

이전 버전(EPUB/PDF 파일을 직접 열어 판권지를 스캔하고, 실패 시 Gemini/LiteLLM으로 AI 판독하던 방식)은 이번 버전에서 제거되었습니다. 대신 DB에 저장된 도서 상세페이지 링크(`link`)를 웹 파싱하는 훨씬 가벼운 방식으로 대체했습니다. 파일 I/O와 외부 AI 호출이 없어 더 빠르고, 서버 리소스도 적게 씁니다.
