통합 도서 검색 설정
국립중앙도서관, 알라딘, 네이버, 구글의 도서 오픈 API 데이터를 동시에 조회하고, 우선순위 규칙에 따라 하나의 서지정보로 합성합니다. 아래 항목은 실제 처리 순서(① 국립중앙도서관 → ② 알라딘 → ③ 네이버 → ④ 구글 → ⑤ 합성 옵션)를 따릅니다.

국립중앙도서관 Open API(ISBN 서지정보)에서 발급받은 인증키입니다. 서지정보(제목/저자/출판사) 합성 시 최우선으로 사용됩니다.

알라딘 OpenAPI 페이지에서 발급받은 TTBKey를 정확히 입력하세요. 표지 이미지의 기본 우선 소스입니다.

네이버 개발자 센터에서 발급받은 애플리케이션 Client ID를 입력하세요.

네이버 개발자 센터에서 발급받은 Client Secret 키를 입력하세요.

구글 북스 API 키를 입력하세요. 비워두면 구글 검색은 자동으로 건너뜁니다(바이패스).

여러 소스에서 결과를 합성할 때, 선택한 소스에 표지 이미지가 있으면 무조건 그 표지를 우선 사용합니다. 서지정보(제목/저자/출판사)는 항상 국립중앙도서관 > 알라딘 > 네이버 > 구글 순으로 병합됩니다.

체크 시, 검색어 단어 목록이 수집된 도서 제목 내에 실제로 정확하게 포함되어 있는 결과만 통과시킵니다. (제목 검색 시에만 적용)
