통합 도서 검색 설정
알라딘, 네이버, 구글의 도서 오픈 API 데이터를 동시에 조회하여 책 정보를 한층 더 풍성하게 채워 넣습니다.
🤖 AI ISBN 판독 설정
도서 파일(EPUB/PDF)의 판권지에서 ISBN을 찾지 못했을 때, AI(Gemini 또는 LiteLLM)로 판독을 보조합니다.

체크 시: DB에 ISBN이 없는 도서는 파일 판권지를 열어 정규식으로 먼저 찾고, 실패하면 아래 AI 설정을 이용해 판독합니다.
해제 시: 파일을 열지 않고 곧바로 제목 텍스트로만 검색합니다(더 빠름). 이 항목을 끄면 아래 AI 설정은 사용되지 않습니다.

구글 Gemini나 본인의 LiteLLM 게이트웨이에 사용될 베어러(Bearer) 토큰 키를 입력합니다.

LiteLLM 또는 OpenAI 호환 프록시 서버의 완전한 Completions 엔드포인트 주소를 입력하세요. (비워둘 시 구글 공식 순수 제미나이 작동)

LiteLLM 라우터에 요청을 보낼 때 적용할 모델 별칭을 적어줍니다. (비워둘 시 기본값: gemini/gemini-3.5-flash-lite)

🔑 서점 오픈 API 설정
알라딘, 네이버, 구글 도서 검색에 사용할 API 키를 입력하세요.

알라딘 OpenAPI 페이지에서 발급받은 TTBKey를 정확히 입력하세요.

네이버 개발자 센터에서 발급받은 애플리케이션 Client ID를 입력하세요.

네이버 개발자 센터에서 발급받은 Client Secret 키를 입력하세요.

구글 북스 API 키를 입력하세요. API 키가 없어도 일부 무료 한도 내에서 기본 검색이 가능합니다.

체크 시, 검색어 단어 목록이 수집된 도서 제목 내에 실제로 정확하게 포함되어 있는 결과만 통과시킵니다.
