통합 도서 검색 설정 (Ver 1.6.1)
국립중앙도서관, 알라딘, 구글의 도서 오픈 API 데이터를 동시에 조회하고, ISBN/제목 기준으로 하나의 도서 정보로 합성하여 채워 넣습니다.

현재 사용 중인 도서 데이터베이스 종류를 선택하세요. 컬럼 조회 방식(PRAGMA / SHOW COLUMNS)이 이 값에 따라 자동으로 분기됩니다.

https://www.nl.go.kr/seoji/ 에서 무료로 발급받은 서지정보 유통지원시스템(Seoji) 인증키를 입력하세요. 서지정보(제목/저자/출판사/출간일 등) 병합 시 최우선으로 채택됩니다.

알라딘 OpenAPI 페이지에서 발급받은 TTBKey를 정확히 입력하세요.

구글 북스 API 키를 입력하세요. API 키가 없어도 일부 무료 한도 내에서 기본 검색이 가능합니다.

고급 옵션 (선택)

도서 파일 내부를 정규식으로 스캔해도 ISBN을 못 찾았을 때만 동작하는 보조 기능입니다. 비워두면 이 단계는 자동으로 건너뜁니다.

구글 Gemini나 본인의 LiteLLM 게이트웨이에 사용될 베어러(Bearer) 토큰 키를 입력합니다.

LiteLLM 또는 OpenAI 호환 프록시 서버의 완전한 Completions 엔드포인트 주소를 입력하세요. (비워둘 시 구글 공식 순수 제미나이 작동)

LiteLLM 라우터에 요청을 보낼 때 적용할 모델 별칭을 적어줍니다. (비워둘 시 기본값: gemini/gemini-3.5-flash-lite)

체크 시, 검색어 단어 목록이 수집된 도서 제목 내에 실제로 정확하게 포함되어 있는 결과만 통과시킵니다.

체크 시, 검색창을 열었을 때 실제 도서의 표지 전후방 페이지를 열어 판권지 속 ISBN을 추적합니다. (저사양 컴퓨터는 해제를 권장합니다.)

여러 API에서 같은 책이 검색되면, 표지·서지정보(제목/저자/출판사/출간일 등) 모두 알라딘 > 국립중앙도서관 > 구글 순으로 값이 있는 소스를 우선 채택합니다.
